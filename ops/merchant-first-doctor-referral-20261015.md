# 仙加味｜先由品牌接待的中醫師轉介規則（2026-10-15）

狀態：使用者已確認的客服與轉介營運規則；不代表醫師端已簽合作銷售協議或具任何特殊藥品銷售資格。

## 主要原則
1. 仙加味官網 → 仙加味 LINE OA (@762jybnm, https://lin.ee/sHZW7NkR) 為商品詢問、規格、價格、一般食品購買、供貨、售後及試喝主要入口。
2. 顧客不確定某項產品適不適合個人身體狀況時，先由仙加味人工客服接待、確認一般商品資訊；不得由客服判斷疾病、藥物交互作用、禁忌、個人用藥及治療。
3. 人工客服認為需醫師評估，或顧客明確要求轉介時，提供章無忌中醫師諮詢資訊（LINE ID @changwuchi；https://lin.ee/1MK4NR9）。
4. 轉介訊息附上顧客可自行發送的來源文字：「您好，我是由仙加味介紹，想詢問【商品名稱】是否適合我的個人情況。」此為來源註記，不代表中醫師必須推薦、成交或返還佣金。
5. 醫師獨立專業判斷。評估後，一般食品及依法可由仙加味販售的商品可由仙加味另行處理供貨、價格及售後；需要醫療機構開立處方、調劑或交付的藥品，依法定流程處理，不能透過一般線上結帳取代。
6. 不把顧客的病史、用藥紀錄或醫療資料自動傳給中醫師、ERP 或其他平台。若要記錄介紹來源，僅記「仙加味轉介」，不要在此欄位存健康細節。
7. 危急症狀引導立即就醫或撥打 119，不等待 LINE 私訊。

## 系統對應
- TS-LINE：`medical-referral-policy.js` 區分敏感健康問題與顧客明確要求轉介；`server.js` 先回覆仙加味人工客服，不直接跳醫師連結。顧客主動要求時才顯示中醫師聯絡卡。
- 官網：`faq.html` 與 `ai-answers.json` 先導流仙加味，再視需要人工轉介。
- ERP：本文件作流程權威；不得僅因醫師轉介即把藥品標記為可供一般線上銷售。

## 待醫師端合作確認
- 對方是否願意識別「由仙加味介紹」的自述來源。
- 是否有合法合規的商品供貨與購買分工；不得將病人轉介與違規利益交換綁定。
- 顧客同意前不得跨帳號分享個人資料，亦不假定對方會提供諮詢結果或交易資料。

## 驗證界線
程式在 GitHub main 更新不等於已在 Render 完成正式部署；實際 LINE 顧客端測試與醫師端流程仍應另行確認。
