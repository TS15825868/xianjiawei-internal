貼文審核、排程與正式發布

目前正式版：產品與試喝優先使用你已核准上傳的正式產品圖／DM／試喝圖；生活情境文優先使用最新上傳 ZIP 的 15 張可直接使用情境圖。每篇貼文卡直接顯示正式配圖判斷，16項審核、重新生成、排程、立即發布與平台結果都在同一套系統完成。

正式規格已同步。 龜鹿膏100g／罐；龜鹿飲30cc／罐（小玻璃罐、裸罐、無貼紙）；龜鹿飲180cc／包（鋁袋）；龜鹿湯塊75g／盒｜8塊裝；龜鹿膠600g／盒｜32塊裝；鹿茸粉75g／罐。

開啟頁面先進安全模式。 平常只顯示簡化狀態；核心連線正常後才開放資料操作，平台 API 背景檢查通過後自動解鎖正式發布。

產品圖／產品DM／試喝圖：一律以目前已核准上傳素材為正式展示來源；產品本體身份維持 products-v3 真實原圖並保持原比例，AI 不得重畫產品。30cc 必須是小玻璃裸罐，180cc 必須保持狹長鋁袋；任何產品圖、DM、試喝圖都不得裁切、拉伸或把產品比例改掉。

最新貼文圖來源：最新使用者 ZIP 共20張唯一圖片，其中15張生活情境圖已同步上線可直接配文，另外5張產品卡維持人工審核，不會自動取代正式產品原圖／正式DM。生活情境圖依季節、情境、環境、冷熱、表情、動作、道具與文案語意比對；有符合的上傳圖就直接使用，只有真的沒有合格來源才重新生成。

任何換圖或改文案後：原核准自動失效、取消既有排程並回到待審核；必須重新完成16項圖文審核後才能排程或發布。

免費重新生成流程：只有正式圖與最新 ZIP 都沒有合格來源時，才使用「圖不符合／文案不符合／全部重新生成」。生成完成後回填或上傳，儲存後自動回到待審核，不會自動核准或發布。

目前正式貼文母庫：母庫張數跟隨目前公開資料並可持續增加，不再限制必須剛好500篇；正式內容依母庫 ID 去重，已發布內容維持鎖定，需要重新生成的內容不得沿用舊錯圖，完成新圖後回到待審核。
