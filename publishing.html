貼文審核、排程與正式發布

目前正式版已把三種媒體角色完全分開：一般產品貼文固定使用六張正式產品圖；明確標示 DM／詳細DM 的貼文才使用各產品修正版詳細DM；試喝貼文固定使用2026-08-12小老闆正式試喝主圖。生活情境文優先使用最新上傳且已核准的Q版小老闆情境圖。每篇貼文仍需完成16項審核後才能排程或發布。

安全檢查中…

正式規格已同步。 龜鹿膏100g／罐；龜鹿飲30cc／罐（小玻璃罐、裸罐、無貼紙）；龜鹿飲180cc／包（鋁袋）；龜鹿湯塊75g／盒｜8塊裝；龜鹿膠600g（1斤）／盒｜32塊裝；鹿茸粉75g／罐。

開啟頁面先進安全模式。 平常只顯示簡化狀態；核心連線正常後才開放資料操作，平台 API 背景檢查通過後自動解鎖正式發布。

產品圖／詳細DM／試喝圖已分開：一般產品貼文只用六張正式產品圖；只有文案明確要求「DM／詳細DM」才用各產品修正版詳細DM；試喝文固定用2026-08-12小老闆正式試喝主圖。products-v3只作產品本體身份、包裝與比例校正，AI不得重畫產品。30cc必須是小玻璃裸罐，180cc必須保持狹長鋁袋；任何媒體都不得裁切、拉伸或改產品比例。

DM修正狀態：30cc詳細DM使用「罐」規格；龜鹿湯塊DM主規格只放「75g／盒｜8塊裝」；龜鹿膠DM主規格只放「600g（1斤）／盒｜32塊裝」。每塊約9.375g與每塊約18.75g只屬詳細資料，不放產品圖或DM主規格。

小老闆正式規則：使用最新核准的精緻Q版小男孩，米白中式上衣、深橄欖綠圍裙、胸前紅色直式「仙加味」印章；小鹿與小烏龜為分開的固定夥伴。情境圖必須依季節、情境、環境、冷熱、表情、動作、道具與文案語意比對，不可混入六張正式產品主圖。

任何換圖或改文案後：原核准自動失效、取消既有排程並回到待審核；必須重新完成16項圖文審核後才能排程或發布。

免費重新生成流程：只有正式產品圖、修正版DM、試喝主圖與最新核准素材都沒有合格來源時，才使用「圖不符合／文案不符合／全部重新生成」。生成完成後回填或上傳，儲存後自動回到待審核，不會自動核准或發布。

目前正式貼文母庫：母庫張數跟隨目前公開資料並可持續增加，不限制固定筆數；正式內容依母庫 ID 去重，已發布內容維持鎖定，需要重新生成的內容不得沿用舊錯圖，完成新圖後回到待審核。
