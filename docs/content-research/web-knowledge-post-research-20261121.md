# 仙加味｜網路知識型貼文素材研究（2026-11-21）

狀態：公開來源研究與候選選題，**非正式貼文、非藥材配方、非發布核准**。承接既有知識圖卡策略與主題去重規則。

## 這輪線上來源及可用方向

1. 農業部食農教育資訊整合平臺「紅棗」：https://fae.moa.gov.tw/map/food_item.php?id=377&type=AS01
   - 網頁具備認識農產、產地、挑選保存、料理加工、飲食文化等架構；並舉紅棗飯、紅棗雞湯作料理例子。
   - 可原創改寫為「乾紅棗常見料理」「紅棗買回家怎麼看標示」「紅棗料理前的備料小知識」。不可直接搬用網站圖片或文字。
2. 衛福部食品藥物管理署「食品廣告合規輔導指引」（2026 年版本）：https://www.fda.gov.tw/tc/includes/GetFile.ashx?id=f639147208057524649
   - 原料合法性、產品本質與廣告內容相符；食品含中藥材須核對產品屬性，不得以食品宣稱醫療效能。
3. 全國法規資料庫「食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則」：https://law.moj.gov.tw/LawClass/LawAll.aspx?PCODE=L0040140
   - 廣告以整體表現判斷；中藥材效能、疾病預防或治療宣稱屬高風險。
4. 衛福部中醫藥司 2026-04-14 公布「得供食品原料使用之中藥材品項及其產品屬性認定基準」**預告草案**：https://www.mohw.gov.tw/cp-2704-86106-1.html
   - 僅供政策變動追蹤；**不得視為已生效規範**，正式使用時應再查現行法規及原料身分。
5. 高雄市衛生局 2026-07-14 提醒網路販售中藥材法律限制：https://health.kcg.gov.tw/News_Content.aspx?n=BC61BA3EC46AD7FB&s=56289628918DACD2&sms=8DA9830902447C5F
   - 紅參、黃耆、麥門冬等不得因網路流行茶飲貼文就直接當成一般食品銷售或提供通用配方；需核對身分、用途與合法通路。

## 社群參考形式（使用者提供的案例）
- 五種食材照片排列＋短標題＋生活情境：易於手機辨識與收藏，但不複製他人照片、版面、文章或「三伏天元氣」療效暗示。
- 六種藥材與克數的配方卡：僅學習條列資訊與視覺清晰度；不搬運藥材配伍、劑量、疾病／血管／養生療效主張。
- 正式仙加味改為：真實食材照片（自行拍攝或有授權）＋可核對食材介紹／保存／料理用途＋品牌署名＋官網延伸閱讀；生活情境與商品關聯自然呈現，不強迫每篇硬塞產品。

## 候選題目（尚未比對全部歷史貼文，不得直接排程）
- K-RED-DATE-01：「乾紅棗可以怎麼入菜？先從紅棗飯與家常湯認識」——官方農業部食農資料可支持料理例子；需確認與歷史家常湯貼文的主題角度不重複。
- K-RED-DATE-02：「紅棗的產地、挑選與保存：看懂食材資訊」——先從農業部資料取證，保存條件需另查並依產品標示。
- K-HERB-LABEL-01：「看到漢方茶包，先看這 3 種標示資訊」——以品名、成分、保存／使用說明為方向，避免自行提供未核准藥材處方。
- K-HERB-FOOD-01：「哪些漢方食材能作食品？先認識食品與藥材的差別」——須專業法規核對，不得用草案直接判定原料合法性。
