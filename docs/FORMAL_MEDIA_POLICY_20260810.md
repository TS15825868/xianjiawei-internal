# 仙加味貼文中心正式媒體與守門規則｜2026-08-10

本文件為貼文中心、500篇母庫、圖文審核、重新生成與部署守門員的最新權威原則。後續若使用者提供更新的正式資料、文案或核准素材，應同步更新能力與資料守門，不得以舊版號或舊固定文案阻擋正確新版。

## 正式產品規格
- 龜鹿膏：100g／罐
- 龜鹿飲30cc：30cc／罐（小玻璃罐、裸罐、無貼紙）
- 龜鹿飲180cc：180cc／包（鋁袋）
- 龜鹿湯塊：75g／盒｜8塊裝
- 龜鹿膠：600g／盒｜32塊裝
- 鹿茸粉：75g／罐

## 正式配圖來源順序
1. **產品／試喝文案**：先使用使用者核准的正式產品 DM／試喝圖；產品本體識別仍以 products-v3 真實原圖為不可取代的權威。
2. **生活情境文案**：使用者最新提供的 zip 為優先素材庫，目前為 `2.zip` 共22張候選。
3. ZIP 候選必須依文案實際比對季節、情境、環境、冷熱、表情、動作、道具與產品脈絡；只有來源是 ZIP 不代表圖片符合。
4. 配圖有三種正式狀態：
   - `approved_existing`：已有符合且可載入的正式圖，可套用後回待審核。
   - `needs_binary_sync`：有符合文案的 ZIP 原圖，但公開二進位尚未同步；此時要保留來源、等待同步，**不得亂換圖，也不得因尚未同步就重生成**。
   - `regenerate_if_missing`：正式產品圖與 ZIP 都真的沒有符合文案的來源時，才進重新生成。
5. 任何套圖、換圖或重新生成後都必須回 `pending_review`，重新完成16項審核；不得自動核准、排程或發布。
6. 產品本體只能使用正式原圖，AI 不得重畫產品；30cc 小玻璃裸罐、180cc 鋁袋為硬規格。

## 重新生成閉環
- 圖不符合／文案不符合／全部重新生成都必須先撤銷舊核准與舊排程。
- 回填或上傳新內容後狀態回 pending_review。
- 不得自動核准、排程或發布。
- 需重生成內容不得沿用舊錯圖。
- 已發布內容維持鎖定；立即發布不受固定排程時段限制，但仍需有效16項審核。
- 沒有合格來源才進重新生成；「合格來源存在但原圖待同步」不等於缺圖。

## 守門原則
- 驗能力、正式資料、圖像權威、真實二進位與安全閉環，**不驗舊版固定句子**。
- UI runtime、post-bank、媒體 cache 等可以正常升版，不得因版本號本身失敗。
- 使用者更新正式資料或核准圖後，守門員必須同步採用新資料；不得拿已退役規格或舊文案反向阻擋新版。
- 必須硬擋：products-v2、產品 AI 重畫、30cc/180cc 外觀錯誤、圖文錯配、拼貼、裁切、假圖片／本機路徑冒充圖片、跳過16項審核、修改後沿用舊核准。
