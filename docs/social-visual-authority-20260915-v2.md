# 仙加味社群視覺正式權威 v2（2026-09-15）

本文件為仙加味貼文、貼文中心、短影片與情境圖的最新正式視覺權威。若與舊圖、舊生成提示、舊素材說明衝突，以本文件與使用者最新確認內容為準。

## 1. 小老闆固定角色

- 固定為 Q 版小朋友、小男孩，不得成熟化、少年化、成人化或寫實化。
- 短黑髮、大眼睛、圓潤親切臉型。
- 米白中式上衣。
- 深橄欖綠圍裙。
- 胸前紅色直式「仙加味」印章。
- 角色外觀以使用者已確認的「仙加味小老闆｜角色定稿圖」為唯一基準。
- 不得因不同貼文而像不同人；只可改變動作、表情、姿勢、季節細節與道具。

## 2. 固定夥伴

- 小鹿與小烏龜必須為兩個獨立角色，不得融合。
- 外觀與比例要延續既有正式 Q 版設定，不得換成其他動物、過度寫實或忽大忽小。
- 不要求每張都同時入鏡；但若入鏡，造型必須一致。

## 3. 真實店面／工作場景權威

仙加味過去主要業務為批發供應中藥店、中醫診所與藥廠，因此店面不是觀光式、古裝式或電影式的傳統中藥鋪。正式圖片不得自行把仙加味改造成大型古典藥櫃、滿牆瓷罐、復古茶館或虛構古街店舖。

正式場景應以使用者 2026-09-15 提供的真實店面／室內照片為基礎：

- 萬華既有街屋店面、金屬與玻璃門面。
- 實際工作型空間，不是展示型古典藥房。
- 室內可見辦公、理貨、收貨、冷藏／冷凍設備、圓木桌、工作櫃與鹿角相關家族物件。
- 可為公開貼文適度整理、簡化雜物、改善光線與構圖，但不得捏造完全不存在的豪華古典中藥鋪。
- 若需品牌感，可使用深藍、米白、深紅、金色、深綠作為視覺整理；仍須保留真實工作場域的個性。
- 萬華外景可使用真實都市巷弄／街屋氛圍，不得固定生成不存在的古城門、古街牌樓或觀光老街。

## 4. 產品本體最高規則

只要貼文圖片出現產品，產品本體必須使用正式產品實物原圖／正式已核准產品素材合成，AI 不得重新設計產品。

禁止：

- AI 重畫產品包裝。
- 改瓶型、改盒型、改鋁袋型態。
- 改標籤、增加不存在貼紙或品牌字樣。
- 拉伸、壓扁、變形、錯誤裁切。
- 任意放大或縮小造成實際比例失真。
- 將 30cc 畫成一般飲料瓶。
- 將 180cc 鋁袋畫成巨大包裝。
- 自創不存在的產品、盒裝或禮盒。

正式規格：

- 龜鹿膏：100g／罐。
- 龜鹿飲30cc玻璃罐：30cc／罐，小玻璃裸罐、無貼紙。
- 龜鹿飲180cc鋁袋：180cc／包，維持正式鋁袋比例。
- 龜鹿湯塊：75g／盒，8塊裝，每塊約9.375g。
- 龜鹿膠：600g／盒（1斤），32塊裝，每塊約18.75g。
- 鹿茸粉：75g／罐。
- 柒玄茶・龜鹿調飲粉目前不得進入公開貼文或圖片。

若沒有可用的正式產品原圖，該張情境圖寧可不放產品，或延後製作，不得由 AI 補畫假的產品。

## 5. 情境圖生成分工

AI 可生成：

- 小老闆與固定夥伴。
- 背景、天氣、季節、料理環境與生活道具。
- 真實店面照片的整理化、插畫化或情境延伸，但不得改變店舖本質。

AI 不可生成／重新設計：

- 正式產品本體。
- 不存在的仙加味店面建築史或古典藥房設定。
- 錯誤品牌標誌、錯誤產品標籤、亂碼公開文字。

## 6. 既有不合格圖處理

下列圖片一律視為不合格並不得回填貼文中心：

- 小老闆不像正式 Q 版小男孩。
- 小鹿／小烏龜走樣或融合。
- 場景被改造成虛構古典中藥鋪。
- 產品由 AI 重畫、包裝／比例／標籤不正確。
- 圖中文字亂碼、錯字或不存在的品牌資訊。

不合格圖直接重做，不得因已生成就繼續使用。

## 7. 發布流程

文案 → 對應情境設計 → 正式角色／真實場景／正式產品素材合成 → 圖文檢查 → 待審核 → 使用者人工審核 → 通過後才排程或立即發布。

沒有合格圖片時維持草稿，不得送審或發布。
