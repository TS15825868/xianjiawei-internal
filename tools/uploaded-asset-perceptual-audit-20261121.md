# 仙加味｜上傳正式素材初步感知去重（2026-11-21）

## 實際資料與方法

直接讀取本次工作環境的三份 ZIP 附件：`產品原圖&原物料(10).zip`、`仙加味產品圖&新DM(20260809-182058).zip`、`網站專用小老闆圖(10).zip`。排除 `__MACOSX`，讀取 PNG/JPG/JPEG/WebP 內容，保留每張原始位元組 SHA-256。

共 36 張圖片，兩兩比較 `36*35/2=630` 組。使用 Pillow 將圖片依 EXIF 方向正規化，縮放裁切為 9×8，轉灰階後計算 64-bit difference hash（dHash）；用 Hamming distance 量化初步相似程度。

## 結果

- 原始 SHA-256 完全相同：0 組。
- dHash Hamming distance ≤ 6：0 組。
- dHash Hamming distance ≤ 12：**1 組**。
- 唯一候選距離 **11**，皆位於 `仙加味產品圖&新DM(20260809-182058).zip`：
  - `6A9560F4-70A3-4B30-B9D9-909D786B04CD.PNG`
  - `26F19EE4-A8BE-4C80-946E-8FD87E8FDB77.PNG`

## 重要限制

dHash 只反映縮圖灰階梯度，不代表內容相同或符合品牌。尤其產品圖／DM 可能共享模板或版面而不構成不合格重複；候選仍需目視比對，不能自動刪除。

這 36 張附件素材**不是** D1 全部 46 篇待審與 115 篇已發布／封存圖片的完整集合；不得將本結果冒充全量貼文視覺去重、圖片正式審核通過或解除 `duplicate=DEFER` 的證據。
